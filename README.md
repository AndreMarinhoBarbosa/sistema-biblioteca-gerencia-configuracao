# Sistema de Gerenciamento de Biblioteca Universitária

Projeto acadêmico desenvolvido para a disciplina de Engenharia de Software.

## Objetivo
Digitalizar atividades da biblioteca universitária, facilitando o acesso ao acervo, reservas, empréstimos, devoluções, histórico e notificações.

## Principais funcionalidades
- Login de alunos e bibliotecários
- Cadastro e pesquisa de livros
- Consulta de disponibilidade
- Reserva de livros
- Registro de empréstimos e devoluções
- Consulta de histórico
- Notificações
- Relatórios
- Gerenciamento de usuários
